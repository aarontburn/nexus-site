# Nexus: Webpage Renderer

## Overview
If your webpage uses method 2, or the `urlPath` in the constructor, your module will not have a renderer process and this section can be skipped.

---

Your module will be using a `<webview>` tag to embed the website. Unlike the `<iframe>`, you can embed most sites without worry about getting blocked from the sites X-Frame-Options (you could technically use an `iframe` instead if the website you want to embed has no restrictions).

The `<webview>` will live within `index.html` and should be initialized from the `renderer.ts` file, using the user agent and partition sent from the process.


The `allowpopups` attribute on the `<webview>` allows you to open links (with a target of '_blank') in new tabs.


For more details on how the renderer works, visit the [Vanilla TS Module Template](<../3 - Vanilla HTML Module/3.2 - Vanilla Module Renderer.md>).


For information about manipulating your `<webview>`, visit [Electrons `<webview>` documentation](https://www.electronjs.org/docs/latest/api/webview-tag)



```typescript
// Sends information to the the process.
const sendToProcess = (eventType: string, ...data: any[]): Promise<void> =>
    window.ipc.sendToProcess(eventType, data);


// Attach event handler.
window.ipc.onProcessEvent((eventType: string, data: any[]) => {
    switch (eventType) {
        case "user-agent": {
            // Create the webview
            const { userAgent, partition } = data[0];

            const url: string = "https://www.nexus-app.net/develop/";
            const html: string = `
                <webview 
                    allowpopups
                    src="${url}"
                    partition="${partition}" 
                    userAgent="${userAgent}"
                ></webview>
            `
            document.getElementById("app").insertAdjacentHTML('beforeend', html);
            break;
        }
        default: {
            console.warn(`Uncaught message: ${eventType} | ${data}`);
        }
    }
});

sendToProcess("init");
```


## Using a Preload Script
You can define a preload script to inject into your webview by creating a `renderer.ts` file and modifying your `webview` tag such as

```ts
<webview 
    allowpopups
    src="${url}"
    partition="${partition}" 
    userAgent="${userAgent}"
    preload="./preload.js"
>
</webview>
```
You can do this to inject a custom script to interact with your renderer process, such as using [`ipcRenderer.sendToHost`](https://www.electronjs.org/docs/latest/api/ipc-renderer#ipcrenderersendtohostchannel-args).

```ts
// Example: Nexus RPI Connect Preload ./src/renderer/preload.ts
const { ipcRenderer } = require('electron');

window.addEventListener('DOMContentLoaded', () => {
    // detect when 'Disconnect' button is pressed on Share Screen mode
    const targetButton = document.querySelector('[data-action="vnc#disconnect"]');
    if (targetButton) {
        targetButton.addEventListener('click', () => {
            ipcRenderer.sendToHost('disconnect-button-clicked');
        });
    }
});
```
```ts
// Example: Nexus RPI Connect Renderer ./src/renderer/renderer.ts
webview.addEventListener('ipc-message', (event) => {
    if ((event as any).channel === 'disconnect-button-clicked') {
        (webview as any).loadURL('https://connect.raspberrypi.com/devices');
    }
});
```

Visit [Electron's Preload documentation](https://www.electronjs.org/docs/latest/tutorial/tutorial-preload) to see what you can do with the preload.


## Overriding link behavior
By default, Nexus will open links in your browser. To override this behavior, you will need to get a reference to your modules [`WebContentsView`](https://www.electronjs.org/docs/latest/api/web-contents-view) using `this.requestExternal("nexus.Main", "get-module-window")` within your `initialize` function.


```ts
// ./src/process/main.ts

export default class SampleProcess extends Process {

    public async initialize(): Promise<void> {
        const response: DataResponse = await this.requestExternal(
            "nexus.Main",
            "get-module-window"
        );
        const view: WebContentsView = response.body;

        view.webContents.setWindowOpenHandler((details) => {
            shell.openExternal(details.url);
            return { action: "deny" };
        });

        view.webContents.on("did-attach-webview", (_, contents) => {
            contents.setWindowOpenHandler((details) => {
                shell.openExternal(details.url);
                return { action: "deny" };
            });
        });
    }
}
```

You can modify this behavior based on your criteria.
