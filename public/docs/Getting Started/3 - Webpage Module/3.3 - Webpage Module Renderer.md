# Nexus: Webpage Renderer

## Overview
If your webpage uses method 2, or the `urlPath` in the constructor, your module will not have a renderer process and this section can be skipped.



Your module will be using a `<webview>` tag to embed the website. Unlike the `<iframe>`, you can embed most sites without worry about getting blocked from the sites X-Frame-Options (you could technically use an `iframe` instead if the website you want to embed has no restrictions).

The `<webview>` will live within `index.html` and should be initialized from the `renderer.ts` file, using the user agent and partition sent from the process.


The `allowpopups` attribute on the `<webview>` allows you to open links (with a target of '_blank') in new tabs.


For more details on how the renderer works, visit the [Vanilla TS Module Template](<../3 - Vanilla HTML Module/3.2 - Vanilla Module Renderer.md>).


For information about manipulating your `<webview>`, visit [Electrons `<webview>` documentation](https://www.electronjs.org/docs/latest/api/webview-tag)



```typescript
// Sends information to the the process.
const sendToProcess = (eventType: string, ...data: any[]): Promise<void> =>
    window.ipc.sendToProcess(eventType, data);


// Attach event handler.
window.ipc.onProcessEvent((eventType: string, data: any[]) => {
    switch (eventType) {
        case "user-agent": {
            // Create the webview
            const { userAgent, partition } = data[0];

            const url: string = "https://www.nexus-app.net/develop/";
            const html: string = `
                <webview 
                    allowpopups
                    src="${url}"
                    partition="${partition}" 
                    userAgent="${userAgent}"
                ></webview>
            `
            document.getElementById("app").insertAdjacentHTML('beforeend', html);
            break;
        }
        default: {
            console.warn(`Uncaught message: ${eventType} | ${data}`);
        }
    }
});

sendToProcess("init");

```
