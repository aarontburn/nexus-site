# Nexus: Webpage Process

## Overview
### Read the [Process](<../Process Overview.md>) for details on how the process works.

The Process of a module that embeds a website is very similar to the Vanilla TS Template module or the Internal Template module.

There are two ways to embed a website.

### Method 1: `<webview>` (recommended)
Using Electrons [`webview`](https://www.electronjs.org/docs/latest/api/webview-tag) tag allows you to embed a website into your module. This is the recommended way because you are able to manipulate the `webview` tag as a `HTMLElement`. This allows you to, if you choose to, manipulate the location and display of the `webview` while also attaching events to it. 

```typescript
// src/process/main.ts

// ...
    private partition: string = `persist:${MODULE_ID}`;

    // This user agent should work on most websites.
    private userAgent: string = session.fromPartition(this.partition)
        .getUserAgent().replace(/Electron\/*/, '');

    /**
     *  The constructor. Should not directly be called, 
     *      and should not contain logic relevant to the renderer.
     */
    public constructor() {
        super({
            moduleID: MODULE_ID,
            moduleName: MODULE_NAME,
            paths: {
                iconPath: ICON_PATH,
                htmlPath: path.join(__dirname, "../renderer/index.html"),
            }
        });
    }


    public async initialize(): Promise<void> {
        this.sendToRenderer("user-agent", {
            userAgent: this.userAgent,
            partition: this.partition,
        });
    }


    public async handleEvent(eventType: string, data: any[]): Promise<any> {
        switch (eventType) {
            case "init": { // This event is sent from the ../renderer/renderer.ts when the frontend is ready.
                this.initialize();
                break;
            }
            default: {
                console.warn(`[${MODULE_NAME}] Uncaught message: ${eventType} | ${data}`);
                break;
            }
        }
    }
```
Because you still have a renderer process, you will need to listen to the `init` signal and act accordingly. In this case, we are sending the user-agent and partition to the renderer to correctly initialize the `<webview>`


### Method 2: `urlPath`
If you simply want to display a website without modifying it in any way, specify the `path.urlPath` within the constructor to the URL of the website.

While this may save a bit of memory (no extra `webview`), this isn't recommended as there will be no way to manipulate the contents of your module.

Your constructor may look like this.
```typescript
// src/process/main.ts

// ...
export default class SampleProcess extends Process {

    private partition: string = `persist:${MODULE_ID}`;

    // This user agent should work on most websites.
    private userAgent: string = session.fromPartition(this.partition)
        .getUserAgent().replace(/Electron\/*/, '')

    public constructor() {
        super({
            moduleID: MODULE_ID,
            moduleName: MODULE_NAME,
            paths: {
                iconPath: ICON_PATH,
                urlPath: "https://www.nexus-app.net/develop/"
            httpOptions: {
                userAgent: session
                    .fromPartition(`persist:${MODULE_ID}`)
                    .getUserAgent()
                    .replace(/Electron\/*/, ''),
                partition: `persist:${MODULE_ID}`
            }
        });
    }

    // initialize() and handleEvent() are both deleted here. 
}
```
In this case, your process will function identically to an internal module. You won't have any access to the DOM.

You can safely delete the `/renderer/` folder and all its contents.
